<AP Nombre="AP_1">
N = {I, A, B, C, F}; // Estados
T = {a, b}; // Alfabeto
P = {a, b, #} // Símbolos de Pila
I = {I}; // Estado Inicial
A = {F}; // Estados de Aceptación
Transiciones:
I ($) -> ($), A : (#) ;
A (a) -> ($), B : (a) ;
B (a) -> ($), B : (a) | (b) -> (a), C : ($) ;
C (b) -> (a), C : ($) | ($) -> (#), F : ($) ;
</AP>
/*
El autómata de pila se llama AP_1
Tiene cinco estados (I, A, B, C, F)
El alfabeto incluye los símbolos a y b.
La pila utiliza los símbolos a, b y # como base.
El estado inicial es I
El estado de aceptación es F.
Se incluyen transacciones vacías con $
*/
